Install

Each archive contains one top-level folder named after the skill. Unzip it into a skills directory.

global — ~/.config/opencode/skills 
curl -fsSL https://isandburn.github.io/skills/typesafe-ai.zip -o /tmp/typesafe-ai.zip && unzip -q -d ~/.config/opencode/skills /tmp/typesafe-ai.zip && rm /tmp/typesafe-ai.zip
project-local — <repo>/.opencode/skills 
curl -fsSL https://isandburn.github.io/skills/typesafe-ai.zip -o /tmp/typesafe-ai.zip && unzip -q -d <repo>/.opencode/skills /tmp/typesafe-ai.zip && rm /tmp/typesafe-ai.zip

The same folder also works in ~/.claude/skills or ~/.agents/skills, and their project-level equivalents.
